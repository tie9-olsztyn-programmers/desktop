## Losujemy 5 pytań
### Surowy kod w `Main`
```csharp
    var wszystkiePytania = pytaniIOdpowiedzi.Keys.ToList();
    var wylosowanePytania = new List<string>();

    var random = new Random();
    while (wylosowanePytania.Count < 5)
    {
        int index = random.Next(0, wszystkiePytania.Count);
        string pytanie = wszystkiePytania[index];

        if (!wylosowanePytania.Contains(pytanie))
        {
            wylosowanePytania.Add(pytanie);
        }
    }

    Console.WriteLine(string.Join(", ", wylosowanePytania));
```

## Pobieramy dane od użytkownika
### Funkcja PokazPytanie
Definiujemy nową funkcję statyczną (w klasie `Program`, ale poza funkcją `Main`)
```csharp
    public static void PokazOdpowiedzi(string pytanie, string[] odpowiedzi)
    {
        Console.WriteLine("Pytanie: " + pytanie);
        Console.WriteLine("Odpowiedzi: ");
        var numerPytania = 1;
        foreach (var odpowiedz in odpowiedzi)
        {
            Console.WriteLine($"{numerPytania}) {odpowiedz}");
            numerPytania++;
        }
    }
```

I używamy jej w `Main`:
```csharap
//...
    var wylosowanePytania = WylosujPytania(pytaniIOdpowiedzi);

    PokazOdpowiedzi(wylosowanePytania[0],pytaniIOdpowiedzi[wylosowanePytania[0]] );

}
```
:::tip Przesteń nazw
- ciągle piszemy `Console.WriteLine`
- jeżeli wskażemy odpowiednią przestrzeń nazw:
    - na początki pliku `using static System.Console;`
    - to możemy pisać tylko `WriteLine`

:::

### Funkcja SprawdzOdpowiedz
Poza `Main`, ale w klasie `Program`
```csharp
      private static bool SprawdzOdpowiedz(string pytanie, int wyborGracza)
    {
        var poprawnaOdpowiedz = pytaniaIPoprawneOdpowiedzi[pytanie]+1;
        return poprawnaOdpowiedz == wyborGracza;
    }
```

Użyjemy tej funkcji w `Main`:
```csharp
//...
     var wylosowanePytania = WylosujPytania(pytaniIOdpowiedzi);

        {
```

### Zamknięcie w pętli
- na razie nasz kod wykonuje się tylko raz
- ale całość, która napisaliśmy, powinna wykonywać się 5 razy
- więc tę część kodu zamknięmy w pętli
```csharp
 public static void Main(string[] args)
    {


        var wylosowanePytania = WylosujPytania(pytaniIOdpowiedzi);

        var iloscPytan = 5;
        while (iloscPytan > 0)
        {
            var numerPytania = 5-iloscPytan;
            PokazOdpowiedzi(wylosowanePytania[numerPytania],pytaniIOdpowiedzi[wylosowanePytania[numerPytania]] );
            bool czyPoprawneDane = int.TryParse(ReadLine(), out var wyborGracza);

            if (!czyPoprawneDane)
            {
                WriteLine("Musisz wpisać liczbę od 1 do 4");
            }
            else
            {
                var czyPoprawna = SprawdzOdpowiedz(wylosowanePytania[0], wyborGracza);
                WriteLine("Twoja odpowiedz: ", wyborGracza);
                if (czyPoprawna)
                {
                    WriteLine("Dobrze!");
                }
                else
                {
                    WriteLine("Źle! Poprawna odpowiedź to ", pytaniaIPoprawneOdpowiedzi[wylosowanePytania[numerPytania]]);
                }
            }
            iloscPytan--;
        }


```
