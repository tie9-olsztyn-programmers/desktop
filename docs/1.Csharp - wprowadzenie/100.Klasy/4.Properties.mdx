# Właściwości / *Properties*
:::note *Properties*
- właściwości (properties) w C# są specjalnymi członkami klasy,
które zapewniają kontrolowany dostęp do pól obiektu.
- właściwości pozwalają na odczyt, zapis lub oba te działania na polach prywatnych klasy,
bez bezpośredniego dostępu do tych pól.
- dzięki właściwościom możemy wprowadzać logikę w czasie przypisywania lub odczytywania wartości,
co daje większą kontrolę nad danymi obiektu.

:::
```csharp
public class Car
{
    private string _brand;  // prywatne pole, które będzie dostępne za pomocą właściwości

    // Właściwość
    public string Brand
    {
        get { return _brand; }  // metoda 'get' zwraca wartość prywatnego pola
        set { _brand = value; } // metoda 'set' ustawia wartość prywatnego pola
    }
}




public class HelloWorld
{
    public static void Main(string[] args)
    {
        Car c = new Car();
        c.Brand = "Bartley";
        Console.WriteLine(c.Brand);
        //c._brand = "New"; // 'Car._brand' is inaccessible due to its protection level

    }
}

```

## Auto-właściwości (*Auto-implemented Properties*)
- Jeżeli nie potrzebujemy dodatkowej logiki w `get` i `set`,
możemy użyć tzw. auto-właściwości, które automatycznie tworzą ukryte pole.
- Jest to skrótowa forma definiowania właściwości:
```csharp
public class Car
{
    public string Brand { get; set; }  // Auto-właściwość
}

Car myCar = new Car();
myCar.Brand = "Honda";
Console.WriteLine(myCar.Brand);  // Output: Honda

```

## Właściwość tylko do odczytu
```csharp
public class Car
{
    public string Brand { get; }  // Właściwość tylko do odczytu

    public Car(string brand)
    {
        Brand = brand;  // Ustawiamy wartość w konstruktorze
    }
}
```
