## Animals
### `Animal`
```csharp
public abstract class Animal(string name, int age) : IAnimal
{
    public string Name { get; } = name;
    public int Age { get; protected set; } = age;

    public abstract string MakeSound();

    public override string ToString()
    {
        return $"{GetType().Name}: {Name}, Age {Age}";
    }
}

```


### `Eagle`
```csharp
public class Eagle : Animal, IFlyer
{
    public Eagle(string name, int age) : base(name, age) { }

    public override string MakeSound() => "Screeeee!";

    public void Fly() => Console.WriteLine($"{Name} soars high!");
}

```

## Services
:::tip Co to jest `service`?
- klasa, która wykonuje jakąś usługę / zadanie dla reszty programu.
- nie reprezentuje zwierzęcia, ucznia, przedmiotu ani rzeczy.
- reprezentuje działanie, np.:
    - zarządzanie listą zwierząt,
    - zapisywanie do pliku,
    - logika aplikacji "jak coś zrobić".

:::


### `Zoo`
```csharp

public class Zoo
{
    private readonly List<Animal> _animals = [];

    public void AddAnimal(Animal animal)
    {
        _animals.Add(animal);
    }

    public void ShowAll()
    {
        foreach (var a in _animals)
        {
            Console.WriteLine(a);
            Console.WriteLine("Sound: " + a.MakeSound());

            if (a is IWalker w) w.Walk();
            if (a is ISwimmer s) s.Swim();
            if (a is IFlyer f) f.Fly();

            Console.WriteLine();
        }
    }
}
```

## `Program` - główny program
```csharp
 public static void Main(string[] args)
    {
        Zoo zoo = new Zoo();

        zoo.AddAnimal(new Lion("Simba", 5));
        zoo.AddAnimal(new Penguin("Pingu", 2));
        zoo.AddAnimal(new Eagle("Aquila", 3));

        Console.WriteLine("=== WELCOME TO THE ZOO ===\n");
        zoo.ShowAll();

        Console.WriteLine("Press any key to exit...");
        Console.ReadKey();
    }
```
