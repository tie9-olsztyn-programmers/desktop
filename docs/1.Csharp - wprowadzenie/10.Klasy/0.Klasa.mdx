# Klasa - definiacja
- Klasa to szablon, z którego można tworzyć obiekty.
- Klasa opisuje cechy (pola) oraz zachowania (metody), które dany obiekt może mieć.

```csharp


public class Car
{
    // Fields/pola/atrybuty
    public string brand;
    public string model;
    public int yearOfProduction;

    // Methods/zachowania
    public void DisplayInformation()
    {
        Console.WriteLine($"Brand: {brand}, Model: {model}, Year of Production: {yearOfProduction}");
    }
}
------------------------------------------------
Utworzenie obiektu

Car myCar = new Car();
myCar.brand = "Toyota";
myCar.model = "Corolla";
myCar.yearOfProduction = 2020;
myCar.DisplayInformation();

```
