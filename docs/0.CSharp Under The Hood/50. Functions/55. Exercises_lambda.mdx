```csharp
public class Character
{
    public string Name { get; set; }
    public string Alignment { get; set; } // np. "Light", "Dark", "Smuggler"
    public int PowerLevel { get; set; }
}

public static class StarWarsData
{
    public static List<Character> GetRoster()
    {
        return new List<Character>
        {
            new Character { Name = "Luke Skywalker", Alignment = "Light", PowerLevel = 9500 },
            new Character { Name = "Darth Vader", Alignment = "Dark", PowerLevel = 12000 },
            new Character { Name = "Yoda", Alignment = "Light", PowerLevel = 15000 },
            new Character { Name = "Emperor Palpatine", Alignment = "Dark", PowerLevel = 14000 },
            new Character { Name = "Han Solo", Alignment = "Smuggler", PowerLevel = 4500 },
            new Character { Name = "Chewbacca", Alignment = "Smuggler", PowerLevel = 5000 },
            new Character { Name = "Obi-Wan Kenobi", Alignment = "Light", PowerLevel = 11000 },
            new Character { Name = "Darth Maul", Alignment = "Dark", PowerLevel = 8500 },
            new Character { Name = "Leia Organa", Alignment = "Light", PowerLevel = 6000 },
            new Character { Name = "Boba Fett", Alignment = "Smuggler", PowerLevel = 7000 },
            new Character { Name = "Kylo Ren", Alignment = "Dark", PowerLevel = 9000 }
        };
    }
}
```


1. The Jedi Archives (Filtering with Where)
Write a LINQ query using a lambda expression to find all characters who belong to the
"Light" alignment.
Assign the result to a variable called `lightSideForceUsers`.

2. The Wanted List (Projection with Select)
The Empire needs names! Use `.Select()` to create an `IEnumerable<string>`
containing only the names of all
characters in the roster.

3. The Rule of Two (Checking with `Count` or `Where`)
Write a lambda expression to count exactly how many characters in the roster belong to
the "Dark" side.

4. Power Rankings (Sorting with `OrderByDescending`)
The Emperor wants to know who is the strongest.
Sort the roster by PowerLevel from highest to lowest using a lambda expression.

5. Finding the Grand Master (Single Item with `FirstOrDefault`)
Use `.FirstOrDefault()` with a lambda expression to find the
specific character whose name is exactly "Yoda".

6. Bounty Hunter Scan (Optimized Check with `Any`)(Remember the tip!)
The local cantina has a strict "No Smugglers" policy.
Use `.Any()` with a lambda expression to check if there is at least one character with
the "Smuggler" alignment in the roster.
It should return a boolean (`true` or `false`).

7. Total Galactic Power (`Aggregation` with Sum)
How much power does the dark side hold? Filter the roster for "Dark" alignment characters,
and then use `.Sum()`
with a lambda expression to calculate the total combined PowerLevel of those characters.

8. The Weakest Link (Sorting and taking with `Min` or `OrderBy`)
Write a query to find the name of the character with the absolute lowest PowerLevel.
(Hint: You can use `.OrderBy()` and `.First()`,
or the `.MinBy()` method if you are using modern .NET).

9. Balance of the Force (Grouping with GroupBy)
Use `.GroupBy()` with a lambda expression to group all characters by their Alignment.
This will create separate groups for "Light", "Dark", and "Smuggler".

10. The Ultimate Pipeline (Chaining LINQ Methods)
Combine your skills! Write a single LINQ pipeline that:
- Filters out anyone with a PowerLevel under 10000.
- Orders the remaining characters alphabetically by their Name.
- Selects only their names as strings.
- Converts the final result to a concrete List (`.ToList()`).
