Funkcja PokazPytanie​

Definiujemy nową funkcję statyczną (w klasie Program, ale poza funkcją Main)

    public static void PokazOdpowiedzi(string pytanie, string[] odpowiedzi)
    {
        Console.WriteLine("Pytanie: " + pytanie);
        Console.WriteLine("Odpowiedzi: ");
        var numerPytania = 1;
        foreach (var odpowiedz in odpowiedzi)
        {
            Console.WriteLine($"{numerPytania}) {odpowiedz}");
            numerPytania++;
        }
    }

I używamy jej w Main:

//...
    var wylosowanePytania = WylosujPytania(pytaniIOdpowiedzi);

    PokazOdpowiedzi(wylosowanePytania[0],pytaniIOdpowiedzi[wylosowanePytania[0]] );

}
Przesteń nazw
  • ciągle piszemy Console.WriteLine
  • jeżeli wskażemy odpowiednią przestrzeń nazw:
    • na początki pliku using static System.Console;
    • to możemy pisać tylko WriteLine

Funkcja SprawdzOdpowiedz​

Poza Main, ale w klasie Program

      private static bool SprawdzOdpowiedz(string pytanie, int wyborGracza)
    {
        var poprawnaOdpowiedz = pytaniaIPoprawneOdpowiedzi[pytanie]+1;
        return poprawnaOdpowiedz == wyborGracza;
    }

Użyjemy tej funkcji w Main:

//...
     var wylosowanePytania = WylosujPytania(pytaniIOdpowiedzi);
