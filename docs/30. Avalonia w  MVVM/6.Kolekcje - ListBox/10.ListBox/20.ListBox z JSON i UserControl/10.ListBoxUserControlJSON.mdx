# ListBox, UserControl, JSON
- zrobimy prostą aplikację, która w `ListBox` będzie wyświetlać bohaterów
z książki "Zbrodnia i kara"
- CRUD na `ListBox`
- zapisywanie danych do pliku JSON
- utworzenie własnej kontrolki `UserControl`


## Przygotowanie projektu
- utwórz projekt:
    - Rider, Avalonia MVVM,
    - ReactiveUI
    - doinstaluj `dotnet add package ReactiveUI.Fody` (automatyczne generowanie kodu)
    - zmieniamy `class MainWindow : ReactiveWindow<MainWindowViewModel>`


## Definicja wyglądu aplikacji - *GET*
`MainWindow.axaml`
```xml
  <StackPanel Margin="20" Spacing="12">
    <ListBox ItemsSource="{Binding Characters}">
        <ListBox.ItemTemplate>
            <DataTemplate>
                <StackPanel Width="400" Spacing="5">
                    <!-- Imię postaci -->
                    <TextBlock Text="{Binding Name}" FontWeight="Bold"/>

                    <!-- Rola w powieści (student, policjant, lichwiarka, itd.) -->
                    <TextBlock Text="{Binding Role}" FontStyle="Italic"/>

                    <!-- Krótki opis postaci -->
                    <TextBlock Text="{Binding Description}"
                               TextWrapping="Wrap"/>
                </StackPanel>
            </DataTemplate>
        </ListBox.ItemTemplate>
    </ListBox>
</StackPanel>
```

## Definicja modelu danych
```cs
public class Character
{
    public string Name { get; set; } = string.Empty;
    public string Role { get; set; } = string.Empty;
    public string Description { get; set; } = string.Empty;
}
```

:::tip Ważna zmiana właściwości `characters.json`
Właściwości/*properties* plik `characters.json należy zmienić
- *Build Action* na *Content*
    - ten plik ma być traktowany jako zawartość aplikacji
    - ten plik ma trafić z całą aplikacją do `output`u
- *Copy to Output Directory* na *Copy always*
    - za każdym razem, gdy uruchamiany jest `Build` projektu
    - nasz plik `.json` będzie kopiowany do folderu wyjściowego `/bin/Debug/net9/`

`string json = File.ReadAllText(FilePath);`
- czyta dane z katalogu wyjściowego `/bin/Debug/net9/`
- więc musimy dopilnować, aby nasz plik `.json` został skopiowany do tego katalogu
:::
