# DataContext

## Czym jest DataContext?
- W poprzedniej lekcji dowidziałeś się, że można łączyć (*binding*) kontrolki między sobą w `xml`.
- A co jeśli chcemy bindować do czegoś, co nie jest kontrolką – np. do zwykłej klasy?

:::important DataContext
- Każde okno/kontrolka w Avalonia ma obiekt, z którego binding pobiera dane.
- Taki obiekt powiniem być wartością wbudowanej właściwości `DataContext`.

:::


## Przykład
- utwórz nowy projekt `AvaloniaApp` (tak jak do tej pory)
- w `MainWindow.axaml`:
    - łączymy właściwość `Text` z właściwością `Greeting`, która powinna być zdefiniowana w jakieś klasie
    - łączymy właściwość `Text` z właściwością `Message`, która powinna być zdefiniowana w jakieś klasie
```xml
<StackPanel Margin="20">
       <TextBlock Text="{Binding Greeting}" FontSize="20"/>
       <TextBlock Text="{Binding Message}"/>
    </StackPanel>
```
- ustawiamy `DataContext` w `MainWindow.axaml.cs` na obiekt klasy,
w której powyższe właściwości zostaną zdefiniowane
```csharp
 public MainWindow()
    {
        InitializeComponent();
        DataContext = new MainWindowData();
    }
```
- utworzymy klasę `MainWindowData.cs`, w której zdefiniujemy właściwości `Greeting` i `Message`
```csharp
public class MainWindowData
{
    public string Greeting { get; set; } = "Hello from ";
    public string Message { get; set; } = "Bindingi almost MVVM";
}
```

:::note aby całość zadziałała
- w pliku `.csproj` (znajdziejsz go zmieniając wyświetlanie z `Solution` na `File System`)
- `<AvaloniaUseCompiledBindingsByDefault>true</AvaloniaUseCompiledBindingsByDefault>`
- zamień wartość `true` na `false`
- w ten sposób wyłączysz konieczność `x:DataType`, czyli określania typu danych

:::

## Zmiana wartości właściwości bindowanych
- Jeżeli po stworzeniu okna, zmienimy wartość właściwości zbindowanych,
- to i tak w oknie będzie wyświetlać się stara wartość, ponieważ
- UI nie zostało poinformowane o zmianie,
- zmień zawartość konstrukotra klasy `MainWindow`
```csharp
   public MainWindow()
    {
        InitializeComponent();
        var data = new MainWindowData();
        data.Greeting = "Initial Value";

        DataContext = data;

        //zmiana powitania
        data.Greeting = "Something new";

        //mimo zmiany wartości i tak w oknie wyświetla się "Initial value"
        Console.WriteLine(data.Greeting);
    }
```
