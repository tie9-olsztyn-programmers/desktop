# List vs ObservebleCollection
- `List<T>`: zwykła lista w C#. UI nie wie, że coś się zmieniło → nie odświeża się.
- `ObservableCollection<T>`: lista, która wysyła zdarzenia (CollectionChanged) → UI reaguje i automatycznie odświeża widok.

**metaforycznie**
- `List<T>` jest jak zeszyt, do którego dopisujesz coś ołówkiem, ale nikt tego nie widzi.
- `ObservableCollection<T>` jest jak zeszyt z mikrofonem, który od razu krzyczy: „Dodałem element!” albo „Usunąłem element!”.
