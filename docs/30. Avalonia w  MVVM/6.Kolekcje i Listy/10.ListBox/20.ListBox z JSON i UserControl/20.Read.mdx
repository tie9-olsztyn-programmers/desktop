# Odczyt danych - READ


## Definiujemy `ViewModel`
Wyobraź sobie, że Twoja aplikacja Avalonia ma listę postaci (`List<Character>`).

Gdy użytkownik wyłączy program, chcesz, żeby te dane nie zniknęły
- mają się zapisać na dysku.
- przy następnym uruchomieniu programu mają się znowu wczytać.

Do tego służą dwa magiczne procesy:
- serializacja (`Serialize`),
- deserializacja (`Deserialize`)

:::note **Serializacja** „zamiana obiektu na tekst”
- to proces przekształcania obiektów w pamięci (np. listy postaci)
- na zwykły tekst w formacie JSON, który można zapisać do pliku.

```csharp
var json = JsonSerializer.Serialize(Characters);   // obiekt -> string
File.WriteAllText("characters.json", json);        // zapisujemy na dysk
```

Po serializacji nasz obiekt jest tekstem w formacie JSON - np:
```json
[
  {"Name":"Gandalf","Level":99,"Class":"Mag"},
  {"Name":"Aragorn","Level":88,"Class":"Wojownik"}
]
```

:::


:::info Deserializacja – „odczytanie tekstu i zamiana z powrotem na obiekt”
To odwrotna operacja: bierzemy tekst JSON z pliku i tworzymy z niego prawdziwe obiekty C#,
z którymi możemy normalnie pracować w aplikacji.

```cs
var jsonData = File.ReadAllText("characters.json");
var list = JsonSerializer.Deserialize<List<Character>>(jsonData);
// teraz „list” to znowu zwykła List<Character> w pamięci.
```

:::

`MainWindowViewModel.cs`
```cs
public class MainWindowViewModel : ViewModelBase
{
    private const string FilePath = "Data/characters.json";

    public ObservableCollection<Character> Characters { get; } = [];

    public MainWindowViewModel()
    {
        LoadCharacters();
    }

    private void LoadCharacters()
    {
        if (!File.Exists(FilePath)) return;
        try
        {
            var jsonData = File.ReadAllText(FilePath);
            var list = JsonSerializer.Deserialize<List<Character>>(jsonData);
            Characters.Clear();
            if (list == null) return;
            foreach (var character in list)
            {
                Characters.Add(character);
            }
        }
        catch (Exception exception)
        {
            Console.WriteLine($"Loading File Error {exception}");
        }
    }
}
```
