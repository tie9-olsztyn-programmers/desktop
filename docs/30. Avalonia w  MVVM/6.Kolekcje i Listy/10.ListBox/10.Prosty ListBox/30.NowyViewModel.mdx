# Rozwiązanie typowe dla MVVM

## `ViewModel` dla `BoardGameModel`.

Zmienimy działanie `<Button>` wewnątrz `ListBox`a tak, aby naciśnięcie go kasowało z listy daną grę.

W folderze `ViewModels` dodajemy plik `BoardGameViewModel.cs`:
```cs

public class BoardGameViewModel : ViewModelBase
{

    public BoardGameModel Model { get; }
    public string Title => Model.Title;
    public string Genre => Model.Genre;
    public int MinPlayers => Model.MinPlayers;
    public int MaxPlayers => Model.MaxPlayers;
    public double Rating => Model.Rating;

    public ReactiveCommand<Unit, Unit> DeleteCommand { get; }

    public BoardGameViewModel(BoardGameModel model, Action<BoardGameViewModel> removeAction
        )
    {
        Model = model;

        DeleteCommand = ReactiveCommand.Create(() => removeAction(this));
        // ← po prostu wywołujemy przekazaną akcję i dajemy siebie jako argument
    }
}

```

:::tip `DeleteCommand`
- `ViewModel` dostaje „przepis” na to, jak usunąć siebie z listy.
- Gdy użytkownik kliknie "Usuń":
  - `ViewModel` wywołuje ten przepis,
  - i przekaże siebie jako argument.


- `removeAction` ta przekazana funkcja
- `this` aktualny `ViewModel` gry (czyli to, co kliknięto)

:::


## Zmiany w `MainWindowViewModel.cs`
- nasz główny `ViewModel` będzie "pracował" na `BoardGameViewModel` a nie na `BoardGameModel`
  - więc typ danych `BoardGameModel` zamieniamy wszędzie na `BoardGameViewModel`
- do konstruktora dodamy metodą ładującą dane `LoadData()`
  - w tej metodzie tworzymy listę obiektów `BoardGameModel` (po staremu)
  - potem do listy `Games`, która teraz przechowuje `BoardGameViewModel` dodajemy
obiekty `BoardGameModel` plus funkcję typu `Action` do usuwania obiektu z listy.

```cs
public class MainWindowViewModel : ViewModelBase
{
    public ObservableCollection<BoardGameViewModel> Games { get; } = [];

    private BoardGameViewModel? _selectedGame;

    public BoardGameViewModel? SelectedGame
    {
        get => _selectedGame;
        set => this.RaiseAndSetIfChanged(ref _selectedGame, value);
    }

    public ReactiveCommand<Unit, Unit> ShowDetailsCommand { get; }

    public MainWindowViewModel()
    {
        LoadData();
        var canShow = this
            .WhenAnyValue(vm => vm.SelectedGame)
            .Select(game => game != null);
        ShowDetailsCommand = ReactiveCommand.Create(
            ShowDetails,
            canShow);
    }

    private void LoadData()
    {
        var models = new[]
        {
            new BoardGameModel
            {
                Title = "Eurobiznes", Genre = "Ekonomiczna",
                MinPlayers = 2, MaxPlayers = 6, Rating = 7.0
            },
            new BoardGameModel
            {
                Title = "Senet", Genre = "Historyczna",
                MinPlayers = 2, MaxPlayers = 2, Rating = 0.0
            } ,
           new BoardGameModel
            {
            Title = "Tryktrak", Genre = "Strategiczna",
            MinPlayers = 2, MaxPlayers = 2, Rating = 4.5
            },
            new BoardGameModel()
            {
                Title = "Grzybobranie", Genre = "Rodzinna",
                MinPlayers = 2, MaxPlayers = 4, Rating = 6.0
            }

        };

        foreach (var model in models)
        {
            Games.Add(new BoardGameViewModel(model, item => Games.Remove(item)));
            // ← przekazujemy lambdę: "gdy ktoś kliknie Delete, usuń ten item z kolekcji Games"
        }
    }

    private void ShowDetails()
    {
        var gameVm = SelectedGame;
        if (gameVm == null) return;

        var g = gameVm.Model;

        Console.WriteLine($"Gra: {g.Title}, {g.Genre}, {g.Rating}");
    }

}
```


## Zmiany w `View` `MainWindow.axaml`
- tym razem `Button` nie musi odwoływać się do rodzica
- `DataContext`em dla elementów `ListBox` jest teraz `BoardGameViewModel`
- a obiekt `BoardGameViewModel` ma metodę `DeleteCommand`

```cs
 <ListBox.ItemTemplate>
                    <DataTemplate>
                        <StackPanel Orientation="Horizontal" Spacing="10">
                            <TextBlock Text="{Binding Title}"  />
                            <TextBlock Text="("/>
                            <TextBlock Text="{Binding Genre}"/>
                            <TextBlock Text=")"/>
                            <Button Command="{Binding DeleteCommand}"
                                    Content="Usuń" />
                        </StackPanel>
                    </DataTemplate>
                </ListBox.ItemTemplate>
            </ListBox>

            <Button Grid.Column="0" Grid.Row="1"
                    Margin="0,10,0,0" Content="Pokaż szczegóły"
                    Command="{Binding ShowDetailsCommand}"
                    HorizontalAlignment="Left"
                    />
```

Już nie pamięta, jaka była pierwotna wersja `Button` z `ShowDetailsCommand`:
- dlatego w `axaml` pokazuję jej końcową wersję
- dlatego też pokazałem kod dla `Command` tej funkcji w `MainWindowViewModel.cs`
